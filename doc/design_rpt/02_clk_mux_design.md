## 1. 模块介绍

`usb_clk_mux` 是 USB 1.1 数字收发器（`usb_dpll_phy`）中负责**产生本地发送时钟 `clk12s`，并在它与恢复时钟 `dclk`
之间无毛刺切换**的子模块，位于 `ref_clk`(48MHz) 时钟域，是 SIE 1× 逻辑时钟 `clk12m` 的**上游开关**。

一句话功能：**内部用 `ref_clk` 分频出本地发送时钟 `clk12s`，再在它与恢复时钟 `dclk` 之间按收发方向无毛刺
选一路输出 `clk12m`**，切换过程保证**不产生毛刺（runt pulse）**。

- **工作频率**：`ref_clk` = 48MHz（4×），既是分频源、又是状态机的时钟；`clk12s` / `clk12m` = 12MHz（1×）；
- **两路被切换的时钟**：`clk12s`（本模块内部由 `ref_clk ÷ 4` 产生）与 `dclk`（DPLL 恢复、频率跟主机晶振，外部输入）；
- **核心思想**：**Intel SIE 4 态无毛刺时钟 MUX**——用"切断旧时钟 → 拉低过渡 → 接入新时钟"的三段手法，
  在事务相位切换（收发交替）时给出干净的 12MHz；
- **关键前提**：两路时钟**频率异步、但边沿都对齐到 ref_clk**（见 §2.5），因此可以用一个 ref_clk 同步状态机
  安全采样它们的电平来做切换——**不需要真正的异步电路**。

```
                       ┌──► clk12m (12MHz, 无毛刺, 供 SIE 1× 逻辑)
   ref_clk (48MHz) ──► │
        dclk (恢复) ──► usb_clk_mux
   rcv (收发方向) ──►   │  （内置 ÷4 分频出 clk12s，再与 dclk 无毛刺切换）
                       （clk12s 仅内部，不对外输出）
```

> 对应我们的设计：**已采用恢复时钟作为真实时钟**——SIE 跑 `clk12m`（本模块切出），接收时 = `dclk`、发送时 = `clk12s`。
> 本模块**现已集成**，是 SIE 1× 时钟 `clk12m` 的唯一上游开关（取舍结论见 §4.5）。

## 2. 模块设计理论和原理及方法

### 2.1 设计动机：为什么 TX/RX 要切时钟

USB 半双工，一个事务里既有收（Token）又有发（Handshake/Data）。两条硬约束：

1. **收的时候必须用 `dclk`**：数据是主机用它的晶振打出来的，相位由主机定。用本地 `clk12s` 采样会因两颗晶振
   ±0.25% 的相对漂移（最坏 ±0.5%）逐 bit 累积错位。`dclk` 每个数据边沿都重新同步一次，相位误差永不累积（位填充兜底）。
2. **发的时候必须用 `clk12s`**：发送时我们是主人，数据按我们自己的节奏往外打，自然用本地 `clk12s`（同步、
   相位确定）。注意**此刻 `dclk` 并没有消失**——一旦锁定，DPLL 就一直自由运转输出 `dclk`（§2.6，只有复位才停）。
   但发送时线上是我们自己发的信号、没有主机的边沿可跟，`dclk` 只能跑标称 4 ref_clk 周期、不再跟踪主机，把它拿去
   发送语义就错了。接收域（跟主机）与发送域（跟本地）必须各用各的时钟。

所以 SIE 状态机必须在**事务相位切换时，在两路时钟之间来回切**。

### 2.2 为什么不能直接 MUX 一接：毛刺

两路时钟异步，若直接 `assign clk12m = rcv ? dclk : clk12s;`，切换瞬间 `dclk` 可能高、`clk12s` 可能低，
MUX 输出会在高低之间抖一下，产生 **runt pulse（毛刺脉冲）**，把下游 1× 逻辑（边沿触发）打乱。这是时钟切换的头号禁忌。

### 2.3 无毛刺手法：切断 → 拉低 → 接入

核心思想：**过渡态把输出恒拉低**，拿"延长低电平"当两路时钟之间的缓冲。

```
     ┌──────── 切断旧时钟 ────────┐
     │                           ▼
  旧时钟 ──► [过渡态: 输出=0] ──► 新时钟
                          ▲
            接入前必等新时钟=0（无缝 0→0）
```

输出**只在新时钟的上升沿重新变高**，永不产生毛刺。无论绝对频率怎么漂，只要守住两条——**断开后必进过渡态、
接入前必等低电平**——切换就是安全的。

> ★ **2026-09-20 修正**：上面两条是**必要**的，但按字面实现还不够——"断开"这一步也必须等旧时钟
> **已经在低电平**（否则会把一个还没走完的高相位拦腰截断，输出多出一个原时钟没有的下降沿）。
> 完整口径与仿真证据见 §4.3。

### 2.4 4 态状态机（Fig.3）

```
     rcv=0 & dclk=0        clk12s=0        rcv=1 & clk12s=0        dclk=0
[0] ────────────────► [1] ─────────► [3] ─────────────────► [2] ──────────► [0]
 输出=dclk              输出=0         输出=clk12s               输出=0          (回到 0)
 (接收)                (过渡)         (发送)                   (过渡)
        reset ─────────────────────────► [3]
```

> 四个迁移条件**统一为"等被切的那一路为低"**（2026-09-20 修正，见 §4.3）。


> 原图画成菱形：0 在上、1 在左、2 在右、3 在下；reset 箭头从下方进入态 3。上电先跑本地时钟 `clk12s`，
> 等收到包、`rcv=1` 才切去 `dclk`。

**状态分类**：

| 状态 | 输出 | 说明 |
|------|------|------|
| ST_RCV(0) | `dclk` | 接收中，用恢复时钟 |
| ST_HOLD1(1) | `0` | RX→TX 过渡，恒拉低 |
| ST_TX(3) | `clk12s` | 发送中，用本地时钟 |
| ST_HOLD2(2) | `0` | TX→RX 过渡，恒拉低 |

**状态跳转表**（当前态 / 条件 / 次态）：

| 当前 | 条件 | 下一 | 说明 |
|------|------|------|------|
| 0 | `rcv=0 & dclk=0` | 1 | 收完，等 dclk 低点，切离接收时钟 |
| 1 | `clk12s=0` | 3 | 等本地时钟低点，接入发送时钟 |
| 3 | `rcv=1 & clk12s=0` | 2 | 发完，等 clk12s **低点**，切离发送时钟 |
| 2 | `dclk=0` | 0 | 等 dclk 低点，接入接收时钟 |
| 任意 | （条件不满足） | 保持 | 每态自环 |
| （复位） | `!ref_rstn` | 3 | 上电默认发送时钟 clk12s |

### 2.5 为什么能跑在 ref_clk（4×）域：dclk/clk12s 都 4× 对齐

这是本模块**最关键也最容易被误解**的一点，直接回答"这状态机跑在哪个时钟域"：

**两路被切换的时钟，频率虽异步，边沿却都落在 ref_clk 沿上。**

1. `clk12s = ref_clk ÷ 4`（本模块内部 2-bit 计数器 `div_cnt[1]` 产生），边沿天然落在 ref_clk 沿上；
2. `dclk` = DPLL 的 `state[1]` 经一级 `always @(posedge ref_clk)` FF 打一拍（`usb_cdr_clk12m`），
   **边沿同样落在 ref_clk 沿上**——DPLL 已经用 4× 量化把主机的异步相位"掰"到了 ref_clk 的格子上，
   只是**周期**（3/4/5 拍）还在跟主机走。

所以两路时钟都是 **ref_clk 域信号**，状态机可以直接在 `posedge ref_clk` 上采样它们的电平，**无亚稳态**。
"等 `dclk=0`""等 `clk12s=0`"在实现上就是每个 ref_clk 拍采样一次电平、满足就跳。

**"自定时"只是逻辑视角**：转移是"等电平就位"（条件驱动），不是"数固定拍"（计数驱动）——这个"电平驱动"
才是无毛刺的根源。但**实现上它不需要电平敏感锁存、不需要异步电路**，就是一个普通的 ref_clk 同步 FSM。

### 2.6 实现方法小结

```verilog
// 1) 内置 ÷4 分频器 → 本地发送时钟 clk12s（50% 占空比 12MHz）
reg [1:0] div_cnt;
always @(posedge ref_clk or negedge ref_rstn)
    if (!ref_rstn) div_cnt <= 2'd0;
    else           div_cnt <= div_cnt + 2'd1;
assign clk12s = div_cnt[1];            // 00,01→0；10,11→1

// 2) 组合：下一状态（四个条件统一取"被切那一路为低"）
always @* begin
    stat_nxt = stat_cur;                  // 默认自环
    case (stat_cur)
        ST_RCV :  if (rcv==1'b0 && dclk==1'b0)   stat_nxt = ST_HOLD1;
        ST_HOLD1: if (clk12s==1'b0)              stat_nxt = ST_TX;
        ST_TX  :  if (rcv==1'b1 && clk12s==1'b0) stat_nxt = ST_HOLD2;  // ★ 低点断离
        ST_HOLD2: if (dclk==1'b0)                stat_nxt = ST_RCV;
    endcase
end
// 3) 时序：ref_clk 同步
always @(posedge ref_clk or negedge ref_rstn)
    if (!ref_rstn) stat_cur <= ST_TX;     // 复位默认 clk12s
    else           stat_cur <= stat_nxt;
// 4) 组合：无毛刺 MUX 输出
assign clk12m = (stat_cur==ST_RCV) ? dclk :
                (stat_cur==ST_TX ) ? clk12s : 1'b0;
```

- **分频器**：2-bit 计数器 `div_cnt[1]` = `clk12s`（50% 占空比 12MHz），与 FSM 同域；
- **组合逻辑** `stat_nxt`：纯组合，无锁存；
- **时序逻辑**：单时钟 `always @(posedge ref_clk)`，复位回 ST_TX；
- **输出**：组合 MUX，靠"状态只会在所选时钟的低点跳"保证无毛刺；
- 全模块**单时钟、可综合**，无 `#`/`initial`/`$display`。

## 3. 模块信号列表

### 3.1 端口信号（对外接口）

| 端口 | 方向 | 位宽 | 说明 |
|------|------|------|------|
| `ref_clk` | in | 1 | 48MHz 参考时钟（4×），分频源 + 状态机时钟 |
| `ref_rstn` | in | 1 | 异步复位，低有效，复位 → ST_TX(3)、`div_cnt`=0 |
| `dclk` | in | 1 | DPLL 恢复时钟（= `usb_cdr_clk12m`），ref_clk 对齐 |
| `rcv` | in | 1 | 接收模式标志（SIE 协议 FSM 产出，clk12m 域电平） |
| `clk12m` | out | 1 | 切换输出的 12MHz（态0=`dclk`，态3=`clk12s`，态1/2=0） |

> `clk12s` 的分频器（2-bit 计数器 `div_cnt`）**在本模块内**，但 `clk12s` **不对外输出**：
> TX 期间 `clk12m` 恒等于 `clk12s`（态 3），TX 1× 逻辑直接跑 `clk12m` 即可，无需单独的 `clk12s` 输出。
> 这正是 MUX 的意义——让 TX/RX 共享同一个 1× 时钟 `clk12m`，中间不需要任何 CDC。

### 3.2 内部关键信号

| 信号 | 类型 | 位宽 | 说明 |
|------|------|------|------|
| `div_cnt` | reg | 2 | ÷4 分频计数器 |
| `clk12s` | wire | 1 | = `div_cnt[1]`，本地发送时钟（内部，不对外） |
| `stat_cur` | reg | 2 | 当前状态 0/1/2/3（现态寄存器） |
| `stat_nxt` | reg | 2 | 下一状态（组合逻辑结果） |
| `dclk_low` / `clk12s_low` | wire | 1 | 两路源时钟的低电平判据（四条迁移条件的口径） |

### 3.3 状态编码常量（localparam）

```verilog
localparam ST_RCV   = 2'd0;   // 输出 dclk（接收）
localparam ST_HOLD1 = 2'd1;   // 输出 0（RX→TX 过渡）
localparam ST_HOLD2 = 2'd2;   // 输出 0（TX→RX 过渡）
localparam ST_TX    = 2'd3;   // 输出 clk12s（发送）
```

## 4. 关键设计点描述及波形

> 本节波形为**示意时序草图**（ASCII）；RTL 与仿真已就绪（`sim/clkmux/`），真实波形可用
> `make debugwave MOD=clkmux` 出 VCD 后经 `tools/render_waveform.py` 捕获补入，届时再配图号与 caption。

### 4.1 复位默认态 = clk12s（态 3）

**问题**：上电/复位后线上没数据、DPLL 锁不上、`dclk` 不存在，SIE 必须有一个可用的默认时钟。

**设计做法**：复位把状态机打到 **ST_TX(3)**，上电先跑本地时钟 `clk12s`，等收到包、`rcv=1` 才切去 `dclk`。
这保证复位后 SIE 立即可跑（哪怕只用于发，或等待接收前的建立）。

### 4.2 两个方向的无毛刺切换

**问题**：切换瞬间若旧时钟还在高、或新时钟还在低，MUX 输出会抖出毛刺。

**设计做法**：分方向逐条守住"断开相位 + 接入相位"：

- **RX→TX（0→1→3）**：`0→1` 等 `dclk=0` 才切（dclk 低点断开，输出 0→0 无缝）；`1→3` 等 `clk12s=0` 才接
  （恒 0 接到 0 无缝），下一个 `clk12s` 上升沿即下游见到的第一个干净沿。
- **TX→RX（3→2→0）**：`3→2` 等 `clk12s=0` 才切（**低点**断开，输出 0→0 无缝）；`2→0` 等 `dclk=0`
  才接（恒 0 接到 0 无缝）。

> ★ **2026-09-20 仿真修正**：本条原写的是「`3→2` 等 `clk12s=1` 才切（高点断开，输出 1→0 是一次干净
> 下降沿）」，仿真证伪 —— 见 §4.3 的修订说明。四个迁移条件现已统一为「低点」。

```
dclk   :  ▁▁▁▁▔▔▔▔▁▁▁▁▔▔▔▔▁▁▁▁
clk12s :  ▁▁▔▔▁▁▔▔▁▁▔▔▁▁▔▔▁▁
rcv    :  ▔▔▔▔▔▔▔▔▔▔▔▔▔▁▁▁▁▁▁▁▁▁▁
state  :  [0]==dclk==[1]==0==[3]==clk12s==[2]==0==[0]
clk12m :  ▁▁▁▁▔▔▔▔▁▁▁▁▁▁▔▔▁▁▔▔▁▁   ← 两处断开都落在旧时钟低点：0→0 无缝，无腰斩
```

### 4.3 切断相位一律取"低点"（2026-09-20 修订）

> 本节原标题为「切断相位的"不对称"（dclk 低点切 / clk12s 高点切）」。首版 RTL 的仿真
> **证伪了"高点切"**，故整节重写。原论证保留在下方"原设计口径"里作为设计史。

**问题**：切离一路时钟时，应该等它走到哪个相位再切？

**修订后的设计做法**：**一律等旧时钟为低（0）才切离**——与接入侧同一条口径：

| 迁移 | 断离条件 | 接入条件 |
|---|---|---|
| `0→1`（RX→TX，断 `dclk`） | `dclk=0` | `clk12s=0` |
| `3→2`（TX→RX，断 `clk12s`） | `clk12s=0` | `dclk=0` |

**为什么"高点切"不成立**（原推论的漏洞）：原口径只检查"能否在旧时钟高时一刀切断"，
认为由此得到的下降沿落在 ref_clk 沿上、"干净"。但**干净 ≠ 合法**——那个下降沿是
**原时钟自己并没有的沿**，而且把高相位拦腰截断：

- 因：`clk12s` 高相位有 2 拍，`ST_TX` 按 `rcv && clk12s` 断离；
- 变：若 `rcv` 恰在 `clk12s` 上升沿那一拍起来，下一拍 FSM 就切走，此时 `clk12s` 仍为高；
- 果：`clk12m` 该高电平只剩 **1 拍**（标称 2 拍），相邻上升沿只隔 **2 拍** → 这一拍跑成
  ~24MHz，并且多出一个 `clk12s` 从未产生的下降沿（经典 runt）。

这正是 §2.3「断开旧时钟后必进过渡态」这条不变式的**不充分之处**：它保证了输出会先归 0，
却没保证归 0 的时刻旧时钟本身已经在 0。补齐这一条（断离条件也看旧时钟相位）后，
`clk12m` 的每个跳变都必然来自当拍所选时钟自己。

**代价**：`rcv` 起来后最多多等 2 拍（41.7ns）才切走 —— 落在事务之间，无影响。
定量证据（波形时刻表）、A/B（4/7 → 7/7）与判据定义见
[clk_mux_verification.md §3/§5](clk_mux_verification.md)。

**原设计口径（已废弃，保留备查）**：

> 这个不对称不是随意选的，是协议状态机自身时序决定的。`rcv` 是 1× 域里、由当前输出时钟
> 打出来的信号：发送期间它跟着 `clk12s` 走，发送收尾那一刻 `rcv` 变 1 时 `clk12s` 恰在高相位；
> 接收期间跟着 `dclk` 走，转发送时 `rcv` 变 0 时 `dclk` 恰在低相位。当时的结论是：只要守住
> 两条不变式——断开后必进过渡态、接入前必等低电平——无论在哪点断都不会出毛刺。
> **该结论错误**，"无论在哪点断都不会出毛刺"正是被仿真推翻的那一句。

### 4.4 `rcv` 信号与 EOP 反射（最容易踩的坑）

**问题**：`rcv` 是本模块里唯一"跨域"进 ref_clk FSM 的信号（它由 1× 协议 FSM 在 `clk12m` 下产生），
并且它反过来决定 `clk12m`——形成**环回依赖**。更糟的是，发完 EOP 后 EOP（SE0）会**反射**回来，接收器可能把
反射当成"新包的开始"，误把 MUX 切回 `dclk`、SIE 进入接收态——但线上没有新包，SIE 会在错误状态下等一个不存在
的 SYNC。

**设计做法**：两层防线——
1. **边沿安全**：`clk12m` = `dclk` 或 `clk12s`，两者边沿都 ref_clk 对齐，所以 `rcv` 的边沿同样 ref_clk 对齐、
   且 4 拍才变一次，ref_clk 采样 `rcv` 无亚稳态；
2. **电平正确**：`rcv` 的产生必须保证"自发 EOP 的反射不被当作新包"（对应我们设计的 `tx_active` 门控，
   发送期间强制 deserial 回 IDLE）。

### 4.5 输出是"派生时钟"——与 Intel 方案对齐的取舍

**问题**：`clk12m` 是一路**派生时钟**，下游 1× 逻辑要拿它当时钟用（而非时钟使能）。`dclk` 周期 3/4/5 ref_clk
不固定，STA 要特殊处理。

**设计做法/说明**：**我们已选定 Intel 方案——用恢复时钟作为真实时钟**，本模块落地集成。两个方案的对比与结论：

| | Intel 方案（**已选定**） | bit_ce 方案（旧） |
|---|---|---|
| 1× 逻辑时钟 | `clk12m`（派生时钟，本模块产出） | `ref_clk`（+ `bit_ce` 使能） |
| 收时钟 | `dclk` 直接当 clock | `dclk` 转成 `bit_ce` 使能脉冲 |
| CDC 代价 | phy↔SIE 同步交接（无异步 CDC），仅 SIE↔pclk 异步 | ref_clk↔pclk 异步 CDC |

选 Intel 方案的理由：**phy↔SIE 之间省掉一个异步 CDC**（`clk12m` 是 `ref_clk` 派生时钟、边沿对齐，同步交接即可），
异步 CDC 只剩 SIE↔backside 一处（`usb_sie_cdc` 四相握手）。代价是 `dclk` 周期 3/4/5 不固定的 STA 痛点照单全收
（`rcv` 用 `set_max_delay` 放松，见 §4.6）。详见 [intel_sie_whitepaper_notes.md §3.5.3/§8](intel_sie_whitepaper_notes.md)。

### 4.6 `rcv` 的 STA 约束（`set_max_delay`）

**问题**：`rcv` 由 1× 协议 FSM（`clk12m`）产出、被 ref_clk（4×）FSM 采样，是**准静态**跨域信号（每事务相位才变
一次，非每周期翻转）。工具默认按 1 个 ref_clk 周期（20.8ns）约束这条路径会报**假违例**，需要放松。

**设计做法**：用 `set_max_delay` 给一个"明显够、又不过分"的延迟上限——它是点对点的纯延迟检查、不依赖
`clk12m`↔`ref_clk` 的边沿关系，正贴准静态信号；比 `set_false_path` 多留一层"保险丝"（延迟真涨上来会报警）：

```tcl
# 方式一：时钟到时钟（需先 create_clock clk12m）
set_max_delay 160 -from [get_clocks clk12m] -to [get_clocks ref_clk]

# 方式二：点到点（推荐——dclk 周期 3/4/5 不定、绕开时钟定义，标 Q 到 D）
set_max_delay 160 \
  -from [get_pins u_sie/rcv_reg/Q] \
  -to   [get_pins u_clk_mux/state_reg/D]
```

- **数值**：ref_clk 周期 20.83ns，4~8 拍 ≈ 83~166ns，取 160 即可（真实延迟 2~3ns，放大几十倍留足余量，
  又能在异常时报警）；
- **为什么不用 `set_multicycle_path`**：它要求 `clk12m` 是干净 ÷N 派生时钟——clk12s（÷4）可以、但 dclk
  周期 3/4/5 不定，工具没法定义成 ÷N 派生时钟，这条走不通；
- **为什么不用 `set_false_path`**：false_path 连 hold 一起关、且不报警，将来改动会静默吞掉真 CDC bug；
- 详见 [intel_sie_whitepaper_notes.md §3.5.3](intel_sie_whitepaper_notes.md#353)。

> 详细验证见 [clk_mux_verification.md](clk_mux_verification.md)（7/7 用例 PASS；该报告 §5
> 记录了本节 §4.2/§4.3 那次高处断离缺陷的波形证据）。
