# wave_debugger.py — VCD 波形调试器 GUI

> 历史 Bug / 陷阱自查台账见同目录 **[`bug.md`](bug.md)** —— 改代码前先翻，遇症状快速定位。

## 功能描述

类似 Verdi / SimVision 的交互式波形调试器 GUI。用于 RTL 仿真调试，支持 VCD 波形加载、信号浏览、波形显示、代码联动等功能。

**核心能力**：
- **3 面板布局**：设计模块树 + 信号列表 + RTL 代码查看器（顶部）；底部是 **「📊 波形 Waveform | 🧾 日志 Log」标签页**，与波形一键切换
- **信号右键 Trace Driver**：右键代码窗口 / 信号列表 / 波形信号标签 → **Trace Driver**，日志列出该信号的**驱动链**（本模块 assign/always 驱动；若是输入端口则自动沿实例端口映射爬到上层实际连线网再追；被子实例输出端口驱动也会指出），并自动跳到真正的驱动行
- **信号右键 Trace Uses**：右键 → **Trace Uses**，日志列出该信号**本模块内**被引用的每一行（assign/always 驱动、敏感列表、实例端口实参、逻辑引用），双击任一行跳到源码
- **代码窗口 Trace 恒可用（不受同名歧义影响）**：右键信号名时**先按当前代码对应的模块作用域消歧**（与双击加波形同一套规则），唯一 → 直接给 `Trace Driver → 全路径`；仍有同名多条 → 改为**子菜单逐条列出各作用域全路径**，绝不把追溯入口藏掉
- **右键认"选中的信号"和点分路径**：右键目标词优先取**编辑器里选中的标识符/层次路径**（右键落在选区内即可，陈旧选区自动忽略），其次取**光标下的点分路径**（`u_dut.rx_error` 这类，直接把同名信号缩到一条），最后才是光标下的单词
- **左右两列垂直同步**：信号标签列与波形区上下滚动恒定对齐（滚轮在**任意一列**上都能滚，标签列上 Ctrl+滚仍是缩放、Shift+滚仍是水平滚）；两列滚动范围与"场景小于视口时的居中偏移"都做了补偿，滚到两端也不会错半行
- **波形双击定位代码**：**双击波形窗口左侧信号名** → 代码窗口快速定位到该信号的声明处
- **日志行双击跳源码**：日志里带 `[文件:行]` 前缀的行双击即跳到代码窗口对应源码行（并短暂黄色高亮）
- **VCD 波形加载**：解析 VCD 文件，显示信号跳变波形
- **模块层级树**：自动扫描 `.v` 源文件，建立模块名→文件映射
- **双列信号列表**：Name+Width | Type，支持搜索过滤，颜色编码
- **RTL 代码查看器**：Verilog 语法高亮，Ctrl+Click / 双击信号名添加波形；**单击模块名双向导航**
- **波形渲染**：单 bit 折线 + 多 bit 总线带值标签，支持缩放/滚动
- **多 Marker**：可拖拽 Mark 线数量**不限**（名字按时间排序自动命名 A–Z、AA、AB…），显示时间差，吸附跳变沿
- **信号颜色自定义**：右键菜单 9 色预设 + 自定义取色器
- **多进制显示**：Hex / Bin / Dec（有符号）/ Oct / Unsigned（**多 bit 默认二进制**）
- **状态名显示**：默认**不**显示状态名（一律二进制）；对单条信号右键 → "Show State Names" 才逐 FSM 识别并显示（识别的常量写法见下方说明，**换 RTL 后"未识别"通常就是常量声明写法没覆盖**）
- **显示变量的某一位 / 位段**：`rx_data[7:0]` 可以只看 `rx_data[1]`（画成 1-bit 高低电平折线），也可以只看 `rx_data[7:4]`（画成多 bit 总线，Hex/Bin/Dec 随便切）。入口两个：波形信号标签列右键 → **➕ 显示位 ▸**（宽度 ≤32 位时逐位列出 `rx_data[7]`…`rx_data[0]`，任何宽度都另有 **指定位 / 位段…** 手输，`1` 或 `7:4` 都认），RTL 代码窗口右键同名信号 → 同一套子菜单（同名多路且按当前模块作用域定不到唯一时不给这个入口，不猜）。切片行**颜色与进制继承父信号**，**插在当前选中行下面**（沿用上面那条规则）；在切片行上右键 → **↩ 显示完整信号** 回到整条总线。切片行的状态名入口**整块隐藏**（数值下标变了，沿用父信号的状态映射会张冠李戴），但进制切换保留。（实现与不变量见 `bug.md` B13）
- **拖拽排序**：鼠标拖动信号标签调整波形行顺序
- **新增波形插在选中行下面**：加信号（信号树双击 / 代码 Ctrl+Click / 粘贴）时**插在当前选中行的下面**，不再一律追加到末尾；**没选中任何行**时仍是追加到末尾（且是顶层信号）。加完**新行自动成为选中行**，所以连续添加会一路往下排（不然每次都插回同一个锚点，顺序会倒过来）。落点与拖拽同一套规则：选中**组内成员** → 新信号自动成为该组成员；选中**折叠的组头** → 插进组首**并自动展开**（否则加完看不见）。
- **信号分组（折叠 / 隐藏）**：在标签列 **Ctrl/Shift 多选**后右键 → 📁 分组 → **新建分组… / 加入分组 ▸ / 移出分组**。组头行只占一行：双击或点最左侧三角 **折叠**（只留组头），右键或工具栏 📁 菜单 **隐藏**（组头+成员整块从波形区消失、但仍留在会话里，随时可恢复）。组头行按 `Delete` = 移除整组（含信号）；菜单里另有"取消分组（保留信号）"。（实现与不变量见 `bug.md` B11）
- **框选缩放**：左键拖拽选定区域放大
- **VCD↔RTL 兼容性检查**：自动验证 + 详细报告对话框
- **会话保存/恢复（跨 case 复用）**：导出 `.wvs` JSON 文件（信号列表 + 颜色/进制/状态名）；加载时**总是映射到当前已打开的 VCD**（未打开任何 VCD 才自动打开会话自带的 VCD）
- **缺失信号报告**：跨 VCD 加载后逐条弹窗报告"哪个信号 + 为什么"无法显示（不存在 / 同名多处 / 模块结构不同等）
- **字体独立调节**：Settings → **"字体大小 Fonts…"** 对话框，4 个子窗口（模块树 / 信号列表 / 代码窗口 / 波形）各自可调字号，拖动即实时预览、可一键恢复默认（模块树 14pt / 信号列表 13pt / **代码窗口 15pt** / 波形 11pt）；代码窗口使用等宽 Menlo
- **默认代码字号人眼舒适**：代码查看器默认 15pt（此前受样式表 11px 压制实际渲染偏小，现已改为字号走每窗口 `QFont`/pt，不再被 QSS 覆盖）

## 使用方法

### 启动

```bash
source .venv/bin/activate

# 直接启动 GUI
python3 tools/wave_debugger.py

# 启动并自动加载 VCD
python3 tools/wave_debugger.py sim/cdr.vcd
```

> **驱动识别覆盖三种写法**：`assign X = …`、**`wire X = expr;`（网络声明即赋值，隐式连续驱动，本项目组合逻辑主力写法）**、
> 过程赋值 `X <= …` / `X = …`；而 `reg … = 初值` 只是上电初值、`parameter/localparam` 是常量，都不算驱动（但仍在 Uses 里按声明标注）。
> 因此一条 `wire` 既会被 Trace Driver 当作驱动行，也会被 Trace Uses 列出 —— 不会"看不见"。

> Trace 只对有源码且已开 VCD 的信号可用。**右键的"目标信号"按 选中文本 → 光标下点分路径 → 光标下单词 依次取**；
> 同名多条时先按当前代码所属模块作用域消歧，仍不唯一才回到子菜单人工挑（发出去的键一律全路径，规避 VCD id 撞号）。驱动追溯规则（用户拍板：**自身模块 + 上层连接**）：
> ① 本模块内 assign/always 赋值到它 → 即驱动；② 它是本模块 **input/inout 端口** → 自动沿实例端口映射爬到
> 上层实际连线网再追（端口改名会追实际网名）；③ 被子实例**输出端口**实参接到 → 指出该实例行；④ 都没有 → 列出本模块内相关引用作候选。
> Trace Uses 只列信号**自身所属模块**内的引用行。

> 说明：状态名识别为**后台探测、按需显示**。添加信号时只自动缓存映射、不显示（默认二进制）；要显示某条信号的
> 状态名才用右键菜单 "Show State Names"。状态名互不混用，各状态变量只显示它自己状态机的常量名
> （同一模块里 `eop_stat_cur` 只会出现 `ST_EOP_*`，不会混入其它 FSM 的名字）。

> **状态名识别覆盖的常量写法**（换 RTL 不认识了先看这条）：`localparam` / `parameter`，**带不带位宽范围都行**
> （`localparam ST_IDLE = 2'd0;` 与 `localparam [1:0] S_IDLE = 2'd0;` 等价）；限定词 `[..]`/`signed`/`integer`/`logic` 可夹在
> 关键字与名字之间；**一行多声明**（`localparam [1:0] A = 2'd0, B = 2'd1;`）与**跨行声明**都认；值可以是字面量
> （二进制/八进制/十进制/十六进制，允许 `_` 分隔）、**其它常量**、或**纯算术式**（`localparam S_B = S_A + 1;`）；
> SystemVerilog `enum {A, B, C}` 按隐式 0,1,2… 认。
> 归属判据是"**这个常量确实和该信号一起用**"（同一行赋值/比较，或位于 `case(信号)` 块内）；两段式 FSM 把比较写在
> 次态变量上（`stat_cur <= stat_nxt;` 而 `case (stat_nxt)`）时，会沿这条直接赋值关系**补一跳**再找，所以状态寄存器照样认全。
> **信号名后可带位选**：`case (stat_cur[1:0])` 与 `stat_cur[1:0] <= stat_nxt[1:0];` 都认
> （规则 7 强制显式位宽，此前会整条认不出 → `bug.md` **B14**）。位选里只认「名字 + 一层 `[..]`」，
> `case (sel + st[1:0])` 这种表达式不会误算成 `sel` 的 case 块。
> 值超出该信号 VCD 位宽的常量会被丢弃（8 位信号配 16 位常量是 RTL 写错，不是工具问题）。

### 会话跨 case 复用（Save/Load Session）

- **保存**：`Ctrl+S` 存 `.wvs`，记录波形信号列表 + 颜色 + 每信号当时显示的**进制**（Hex/Bin/Dec/Oct…）+ 状态名 + 每级作用域模块名 + **信号分组** + **位切片**（version 5；仍可读旧 v1–v4 文件，旧文件无 `groups`/`bits` 键 → 行为与加这些功能之前完全一致）。加载时逐信号把保存的进制还原到匹配到的信号上（同文件完整恢复与跨 case 映射都恢复进制）。
  - 分组的 `members` 存的是 `signals[]` 的**下标**（不是 full_path —— 同一 full_path 可以出现多次，下标才唯一）；**被折叠 / 隐藏的组成员也会存进去**，所以收起的分组存盘后照样能原样恢复。
  - **位切片行存的是父信号的身份**（full_path / leaf / width / 作用域全是父的）+ 一个 `bits: [msb, lsb]`，载回时按父信号重新切一刀 —— 所以跨 case（换 VCD、位宽或模块结构变了）照样能重新适配；新 VCD 里父信号位宽不够时该行**不静默消失**：报告里单列一条 `✗ 位段超出范围`（status = `FAIL_BITS`）。
  - `Ctrl+R` 重新加载 VCD 走的是**同一套**打包格式与槽位重建，分组结构一并保留。
- **加载**：`Ctrl+L` 时**总是映射到当前已打开的 VCD**（不自动切换）。仅当尚未打开任何 VCD 时才自动打开会话自带的 VCD 做完整恢复。
  - 当前 VCD 与会话记录的相同 → 完整恢复（含 Marker / 缩放 / 滚动位置）。
  - 当前 VCD 不同 → 只把信号列表映射过来，忽略 Marker/缩放；每个信号的恢复按以下顺序：
    1. **完整路径精确匹配**；
    2. 找不到时按**"实例之下的模块层级 + 信号名"**匹配（容忍顶层 tb 名 / 例化名改名，如 `tbA.u_dut.X` → `tbB.u_dev.X`）；
    3. 都不行则**不擅自挑**，弹窗逐条列出"哪个 + 为什么"。
  - 无法显示的原因分类：信号名在当前 VCD 不存在 / 同名信号存在于多个作用域（有歧义）/ 仅存在于模块结构不同的其它作用域；位宽或类型变化仍照常显示但会在说明里注明。
  - **分组掉信号**：组内成员掉一个 → 组不散架、少一个成员；整组一个都没解析出来 → 丢弃该组并在报告里单列一行（**不静默消失**）。
- 报告对话框支持 **"复制到剪贴板"**（制表符分隔，可直接粘进表格/文本）。
- **`Ctrl+L` 载会话 / `Ctrl+R` 重载 VCD 后波形是有数据的**（2026-09-20 修）：此前这两条路径只重建行、没取跳变数据，所有行都画成红框 "no data"（详见 `bug.md` B13）。

## 输入/输出

- **输入**：VCD 文件 + 项目 RTL 源码目录（`src/`, `tests/`）
